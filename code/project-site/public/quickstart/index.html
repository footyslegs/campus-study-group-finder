GETTING STARTED

Quickstart

Launch the project site, then run the existing Project 1 application.

Two separate applications

This documentation site runs on Node.js. The current Project 1 starter runs on Java and Maven. The planned campus web application is not yet available.

Launch this project site

  1. Install Node.js

    Use Node.js 18 or later. Confirm the installation with node --version.

  2. Open the project-site folder

    Extract the submission ZIP and open a terminal inside project-site. If you cloned the repository, open code/project-site instead.

  3. Start the server

    Run the command below. The site uses built-in Node modules, so no dependency installation is required.

npm start

Open http://localhost:3000. You should see the Campus Study Finder landing page. Stop the server with Ctrl + C.

Launch the Project 1 application

  1. Install the prerequisites

    Install Git, JDK 17 or later, and Apache Maven. The project targets Java 17 and declares JavaFX 21.0.2 in pom.xml. JavaFX dependencies are downloaded by Maven; the first build needs internet access.

  2. Clone the repository and select dev

    Use the commands below from your preferred projects folder.

git clone https://github.com/footyslegs/campus-study-group-finder.git
cd campus-study-group-finder
git checkout dev

3. Verify your environment and build

java -version
mvn -version
mvn verify

A successful verification completes Checkstyle, JUnit tests, and the configured JaCoCo coverage check. The coverage requirement is 90% line coverage for checked packages; GUI-only packages are excluded.

4. Launch the desktop application

mvn javafx:run

Run this command from the repository root containing pom.xml. A desktop session is required. The window title should read Temperature Converter.

5. Try a conversion

Enter 72 in Fahrenheit and select To Celsius. The Celsius field should show 22.22. Follow the current feature guide for more examples.

Troubleshooting

“node” or “mvn” is not found
Install the corresponding prerequisite and make sure its executable is on your PATH. Open a new terminal after installation.
Port 3000 is already in use
On macOS/Linux run PORT=3001 npm start. In PowerShell run $env:PORT=3001; npm start. Then open localhost:3001.
Java or dependency errors
Check mvn -version to confirm Maven uses JDK 17 or later. Make sure the first build can reach Maven Central.
Where are the study groups?
They are planned features. This repository currently launches the JavaFX starter shown above.
