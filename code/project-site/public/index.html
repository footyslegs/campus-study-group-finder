PROJECT CONCEPT / ILLUSTRATION
THE IDEA

Less searching.
More shared learning.

A project designed around the everyday work of studying: finding a group for your course, planning a session, and keeping everyone in the loop.

Meet the features ↗
WHERE THE PROJECT IS TODAY

A foundation you can run.

Current build: JavaFX starter

From a working pipeline
to a campus application.

The repository currently contains a temperature-converter application used to establish the DevOps pipeline. Study-group capabilities are planned and are not implemented in this build.

The starter uses JavaFX, Maven, Checkstyle, JUnit, and JaCoCo, with GitHub Actions for continuous integration.
