Temperature converter

The working application used to establish and exercise the project’s DevOps pipeline.

First complete the quickstart and launch the desktop window with mvn javafx:run.

Convert Fahrenheit to Celsius

  1. Enter a Fahrenheit value

    Type 72 in the Fahrenheit field.

  2. Select To Celsius

    Click the To Celsius button on the same row.

  3. Read the result

    The Celsius field updates to 22.22. Results are formatted to two decimal places.

Convert Celsius to Fahrenheit

  1. Enter a Celsius value

    Type 20 in the Celsius field.

  2. Select To Fahrenheit

    Click To Fahrenheit on the Celsius row.

  3. Read the result

    The Fahrenheit field updates to 68.00.

Correct invalid input

  1. Try a nonnumeric value

    Enter hello in Fahrenheit, then select To Celsius.

  2. Read the message

    The application displays Fahrenheit must be a number. beneath the fields.

  3. Correct the value

    Replace the text with a valid number and select the conversion button again. A successful conversion clears the error message.
